Usage: qmstrace check [OPTIONS]

  List every violation, gap and suspect, each with its next move.

  While authoring, gaps do not fail: they are the work not done yet. Under
  --strict — the gate a pull request passes — they do. Violations always fail.
  Suspects never fail, even under --strict: an edit or a passing test does not
  record review.

Options:
  --strict          The gate: gaps fail too; suspects never fail.
  --quiet           Findings only — what could not be verified still shows.
  -C PATH           Run as if qmstrace had been started in PATH, as with git -C.
                    Before or after the command.
  --workspace FILE  Select a checkout map; overrides QMSTRACE_WORKSPACE and
                    automatic discovery. Before or after the command. Relative
                    files start at the effective -C directory.
  --json            Emit versioned JSON for agents, including handled errors.
                    Before or after the command.
  --help            Show this message and exit.
