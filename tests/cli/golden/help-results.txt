Usage: qmstrace results [OPTIONS] {REPORT...}

  Match reports to scanned tests and their explicit verifies links.

  Each report is pytest JUnit XML or a TRX file (dotnet test --logger trx); its
  root element decides which. Several reports are read as one, in any order: a
  run in two of them counts once, with its worst verdict. Informational: failing
  tests and partial matches still exit 0. Unmatched entries are listed; reports
  with no matches exit 2. Relative report paths start at -C or the current
  directory, not the discovered repo root. A report outside the repo is shown by
  its file name. The reports' commit is not verified.

Arguments:
  REPORT...  Pytest JUnit XML reports or TRX files, read as one —
             TestResults/*.trx.  [required]

Options:
  -C PATH           Run as if qmstrace had been started in PATH, as with git -C.
                    Before or after the command.
  --workspace FILE  Select a checkout map; overrides QMSTRACE_WORKSPACE and
                    automatic discovery. Before or after the command. Relative
                    files start at the effective -C directory.
  --json            Emit versioned JSON for agents, including handled errors.
                    Before or after the command.
  --help            Show this message and exit.
