Usage: qmstrace init [OPTIONS]

  Initialize the selected directory; refresh managed guidance in an existing
  traced repo.

  Existing configuration and unrelated guide/settings content are preserved.
  Repeating init changes nothing. The starter is repo-owned, with no invented
  origins or baseline tags; a new product repo's starter declares the item types
  of the language its build files name, and init says which it chose. Commit the
  generated files after reviewing the rules and scan paths.

Options:
  --subject <str>   New repo subject name; default: product.
  --key <str>       New repo ID key; default: PROD.
  --language <str>  Language the new starter declares item types for: python or
                    csharp.
  -C PATH           Run as if qmstrace had been started in PATH, as with git -C.
                    Before or after the command.
  --help            Show this message and exit.
