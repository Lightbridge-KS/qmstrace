Usage: qmstrace impact [OPTIONS] {ID…}

  Show the combined downstream items and upstream origins of several starting
  items.

  The Impacts line is a candidate for review, filtered by configured baseline
  types. It stops at this repo's edge. Any unseen starting ID rejects the whole
  request.

Arguments:
  ID…  One or more item IDs visible to this run.  [required]

Options:
  -C PATH           Run as if qmstrace had been started in PATH, as with git -C.
                    Before or after the command.
  --workspace FILE  Select a checkout map; overrides QMSTRACE_WORKSPACE and
                    automatic discovery. Before or after the command. Relative
                    files start at the effective -C directory.
  --help            Show this message and exit.
