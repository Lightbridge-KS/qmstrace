Usage: qmstrace ledger [OPTIONS] COMMAND [ARGS]...

  The project side's verbs — run them in the ledger repo, where
  qmstrace.schema.toml is.

Options:
  --help  Show this message and exit.

Commands:
  copy-schema  Copy the project's trace schema into its product repos.
  check        Judge every repo of the project together — the gate with
               --strict.
  thread       Trace one item across every repo: what it derives from, what
               hangs off it.
  impact       What changing several items affects across every repo of the
               project.
